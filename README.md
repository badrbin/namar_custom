# Namar KDT

تطبيق Frappe 15 مستقل للمسار: **نتائج التخصيم ← إنشاء أمر قص ← طباعة**.

يحتفظ بالربط بطلبات المواد والمقاسات والكميات والباركود ومنع التكرار والصلاحيات في النسخة المرجعية الحية. الطباعة لا تسجّل تنفيذ القص، وهذا المسار لا يرسل أوامر إلى الماكينة ولا ينشئ حركة مخزون.

النطاق الحالي هو `testnamar.u.frappe.cloud` فقط. التثبيت لا يفعّل التطبيق؛ التفعيل والرجوع عبر `namar_kdt.migration.activate` و`namar_kdt.migration.deactivate`، بعد التحقق من نسخة السكربتات والتقرير وبنية السجلات.

أسماء السجلات الحالية وبياناتها محفوظة. يعتمد التطبيق على تخصيصات Namar الموجودة، ولا يستبدل تعريفات DocType أو يستورد بيانات طلبات أو أوامر من Git. ملفات `reference/schema.json` مرجع بنية فقط، وليست fixtures تعمل عند التثبيت.

فرع `namar_kdt` مصدر تطبيق مستقل في مستودع `badrbin/namar_custom`. لا يدمج مع فروع تطبيق Namar أو Demo.

## التحقق

```sh
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/test_frontend.js
```

قبل التفعيل، تقارن أداة القراءة `namar_kdt.migration.compare_report` التقرير المخزن مع Python، وتقارن استدعاءات API القراءة القديمة والجديدة. بعد التفعيل يجب إعادة تحميل الواجهة بالكامل.
