# Namar KDT

تطبيق Frappe 15 مستقل للمسار: **نتائج التخصيم ← إنشاء أمر قص ← طباعة**.

يحتفظ بالربط بطلبات المواد والمقاسات والكميات والباركود ومنع التكرار والصلاحيات في النسخة المرجعية الحية. الطباعة لا تسجّل تنفيذ القص، وهذا المسار لا يرسل أوامر إلى الماكينة ولا ينشئ حركة مخزون.

النطاق الحالي هو `testnamar.u.frappe.cloud` فقط. التثبيت لا يفعّل التطبيق؛ التفعيل والرجوع عبر `namar_kdt.migration.activate` و`namar_kdt.migration.deactivate`، بعد التحقق من نسخة السكربتات والتقرير وبنية السجلات.

أسماء السجلات الحالية وبياناتها محفوظة. يعتمد التطبيق على تخصيصات Namar الموجودة، ولا يستبدل تعريفات DocType أو يستورد بيانات طلبات أو أوامر من Git. ملفات `reference/schema.json` مرجع بنية فقط، وليست fixtures تعمل عند التثبيت.

فرع `namar_kdt` مصدر تطبيق مستقل في مستودع `badrbin/namar_custom`. لا يدمج مع فروع تطبيق Namar أو Demo.

## البحث وتوليد التقرير

افتح «نتائج التخصيم»، واختر الفلاتر المطلوبة، ثم اضغط **توليد التقرير**. لا يشغّل فتح الصفحة أو تغيير الفلاتر الحساب الكامل. تتيح القوائم البحث وتعرض الاختيارات أولًا، وتتوفر خيارات اللون قبل أول توليد.

يحسب التوليد النتائج الحديثة مباشرة؛ لا يعتمد إنشاء أمر القص على تقرير محفوظ قديم. تغيير الفلاتر يخفي النتائج السابقة ويوقف إنشاء أمر القص وتعديله والتصدير حتى التوليد التالي. إذا تغيرت الفلاتر أثناء التحميل، تُهمل استجابة الطلب السابق. يبقى زر إعادة تحميل التقرير وسيلة توليد صريحة، ولا يؤثر هذا السلوك في التقارير الأخرى.

## استبعاد التصنيع السابق من القص

أي كمية تصنيع موجبة في سطر الباب تستبعد مساهمته في المكونات من أمر قص جديد. يُستخدم عداد التصنيع الحالي، مع علامة التصنيع القديمة بديلًا عند غياب كمية موجبة؛ لا تكفي حالة طلب المواد العامة أو صناعة مكوّن مستقل لإثبات تصنيع الباب.

يبقى السطر المصنّع جزئيًا مستبعدًا كاملًا مؤقتًا وفق السياسة المعتمدة، ويظهر مثلًا «تم تصنيع 2 من 5 — المتبقي 3». تخصيص المكونات هنا على مستوى سطر المصدر؛ لا يقسّم هذا الإصلاح الكمية على الوحدات، رغم أن ملصق التصنيع الحالي يدعم رقم الوحدة. تبقى المصادر غير المصنّعة متاحة، وتظهر الكمية المستبعدة من المكوّن منفصلة عن عدد الأبواب.

تعاد قراءة العدادات تحت قفل المصدر قبل الحجز، وتنعزل القراءات بين الطلبات. لا يُنشأ أمر فارغ أو مرجع سابق وهمي أو تسجيل إنجاز لمجرد تصنيع المصدر. تبقى الأوامر السابقة وباركودها وطباعتها وسجلاتها محفوظة؛ يُحفظ مصدرها المصنّع عند التعديل، ويمكن تعديل بقية المصادر. يمنع تخصيص المصدر المصنّع عبر إنشاء جديد أو إضافة أو إعادة قص، ويطبّق الحارس القاعدة قبل اعتماد دفعة قص قديمة.

## التحقق

```sh
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/test_*.js
```

قبل التفعيل، تقارن أداة القراءة `namar_kdt.migration.compare_report` التقرير المخزن مع Python، وتقارن استدعاءات API القراءة القديمة والجديدة. بعد التفعيل يجب إعادة تحميل الواجهة بالكامل.
